# M4 剩余任务启动提示词包

**权威依据**：AGENTS.md §0、§4.4、§5、§7、§8、§9、§10、§11；docs/00-12；用户 2026-08-10 明确授权建立提示词资产。  

## 定位

本目录保存的是**可复用的任务启动提示词资产**，用于把每项任务的治理入口、工程环境、开发过程和验收标准表达一致。

它们不是 `.plan/` 执行计划，不代表任务已经获准开工，也不代表可以跳过 Git、测试、独立审查或用户授权。

## 使用规则

1. 每次只可复制/使用一个具体任务提示词。
2. 使用前仍必须按 AGENTS.md §0 读取权威文件，并核验当时的 Git 与任务事实；文件内的历史快照不能代替实时核验。
3. 只有同时满足 AGENTS.md §4.4 的三项前置条件，才允许把提示词转化为该任务的唯一 `.plan/` 执行计划：
   - 上一任务已完成并登记；
   - 用户已明确选择并批准当前任务；
   - 当前任务即将进入实施。
4. 实际开工时，必须将 04-Todo 状态更新为 in_progress、创建唯一 `.plan/` 文件、建立隔离分支与隔离运行根；本目录文件不得代替其中任何一项。
5. 本目录只列出任务范围、权威入口、风险点和验收主题；具体文件清单、实施步骤、RED 用例、命令执行记录和证据必须在获得开工授权后写入当次 `.plan/`，不得提前伪造实施事实。
6. 未经用户单独授权，不得因使用提示词而 commit、merge、push、启动下一任务或操作真实业务数据。
