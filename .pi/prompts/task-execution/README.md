# 任务执行提示词包

**状态**：✅ 受控参考资产（首次建立：2026-08-10；2026-08-13 增补 T-M5-004 续作 / 复验治理提示词）
**适用范围**：通用标准提示词；历史 M4 任务提示词（T-M4-014～T-M4-021）；M5 已登记任务提示词（T-M5-003、T-M5-004）。
**权威依据**：AGENTS.md §0、§4.4、§5、§7、§8、§9、§10、§11；docs/00-12；用户对各具体任务的明确选择和开工授权。

## 定位

本目录保存**可复用的任务启动 / 执行上下文提示词资产**，用于把每项任务的治理入口、工程环境、开发过程、风险边界和验收主题表达一致。

它们不是 `.plan/` 执行计划，不代表任务已经获准开工，也不代表可以跳过 Git、测试、独立审查、用户端到端测试（真机 UAT）或用户授权。任何具体任务的实时状态，始终以 `docs/04-任务清单-Todo-List.md` 与唯一 `.plan/` 为准。

## 使用规则

1. 每次只可复制/使用一个具体任务提示词，并必须同时提供 `00-标准任务执行提示词.md`。
2. 使用前仍必须按 AGENTS.md §0 读取权威文件，并核验当时的 Git、任务、分支和运行时事实；文件内历史快照不能代替实时核验。
3. 只有同时满足 AGENTS.md §4.4 的三项前置条件，才允许把提示词转化为该任务的唯一 `.plan/` 执行计划：
   - 上一任务已完成并登记；
   - 用户已明确选择并批准当前任务；
   - 当前任务即将进入实施。
4. 任务已 `in_progress` 时，提示词只能辅助执行既有唯一计划；不得新建第二个详细计划，不得以 prompt 覆盖或重写 `.plan/` 的实时裁决。
5. 本目录只列出任务范围、权威入口、风险点和验收主题；具体文件清单、实施步骤、RED 用例、命令执行记录和证据必须在获得开工授权后写入当次唯一 `.plan/`，不得提前伪造实施事实。
6. 每个任务的收尾除自动化质量门外，均必须有真实 Electron + 新隔离数据根 + 纯 UI 操作的真机 UAT，并保留步骤级证据；自动化 E2E、fixture、renderer 注入均必须与原生真机 UAT 分开记录。
7. 未经用户单独授权，不得因使用提示词而 commit、merge、push、启动下一任务或操作真实业务数据。
