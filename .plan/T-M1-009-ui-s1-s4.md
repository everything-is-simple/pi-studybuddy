## 2. 范围与非目标

### 范围

- **5 个 Tab 业务组件**：
  - `HomeTab` — S1 每日学习简报（`tasks.dailyBrief` + 待办列表 + 考试倒计时）
  - `MaterialsTab` — S2 资料上传与管理（`materials.list` + 状态标识 + 上传入口 + 转换/生成笔记操作）
  - `NotesTab` — S2 笔记预览与导图（`notes.get` + `notes.getMindMap` + 知识模块列表 + 学习状态流转）
  - `PracticeTab` — S3 限时练习（`practice.createSession` + `getQuestions` + `submit` + `getResult` + 计时器 + **作答前防泄露**）
  - `MistakesTab` — S4 错题改错与薄弱点（`mistakes.list` + `get` + `confirmErrorCause` + `suggestErrorCause` + `redo` + `weakPoints.list` + 六分类确认 + AI 不确定标记）
- **AppShell 路由改造**：根据 activeTabId 渲染对应 Tab 组件（替换 M0 占位内容）
- **RPC 客户端注入**：App.tsx 创建 RpcClient，通过 props 注入各 Tab 组件（便于测试 mock）
- **公共组件**：
  - `TabContainer` — Tab 内容容器（统一 padding/滚动）
  - `EmptyState` — 空状态提示（无学期/无课程/无数据）
  - `LoadingState` — 加载中提示
  - `ErrorState` — 错误提示（中文可操作消息，不含内部栈/SQL/路径/UUID）
  - `ShortId` — 短 ID 显示（不展示完整 UUID，§11.1 铁律）
- **防泄露断言**：PracticeTab 作答前渲染不含 correct_answer/acceptable_answers/explanation 字段
- **隐私边界**：所有 UUID 显示走 ShortId 组件（只显示前 8 位 + …）
- **TTS 朗读按钮预留**：笔记/错题/练习结果区域预留朗读按钮位置（onClick 调用 tts.speak，本任务实现按钮 + 调用，全局控制条留待 T-M2-008）
- **静态渲染测试**：5 个 Tab 组件 + 公共组件 + 防泄露断言 + 隐私边界断言

### Tab 组件 Props 签名

```typescript
// 所有 Tab 组件接收 rpcClient + 上下文（semesterId/courseId）
interface TabProps {
  rpc: RpcClient;
  semesterId?: string;
  courseId?: string;
  onNavigate?: (tabId: string, params?: Record<string, unknown>) => void;

```

### AppShell 路由

```typescript
// activeTabId → 对应 Tab 组件
function renderTab(activeTabId: string, props: TabProps): React.JSX.Element {
  switch (activeTabId) {
    case "home": return <HomeTab {...props} />;
    case "materials": return <MaterialsTab {...props} />;
    case "notes": return <NotesTab {...props} />;
    case "practice": return <PracticeTab {...props} />;
    case "mistakes": return <MistakesTab {...props} />;
    default: return <EmptyState message="该标签页待后续里程碑填充" />;
  }
}
```

## 5. 关键约束落实

### 5.1 防泄露铁律（09-UI §4.6 + §7.2）

PracticeTab 作答前阶段：
- 只调用 `practice.getQuestions`（返回 QuestionDTO[]，不含 correct_answer/acceptable_answers/explanation）
- 渲染时**绝不**访问 question 对象的 correct_answer/acceptable_answers/explanation 字段
- 测试断言：渲染输出 HTML 不含 "correct_answer" / "acceptable_answers" / "explanation" 字符串

PracticeTab 结果阶段（submit 后）：
- 调用 `practice.getResult`（返回 PracticeResult，含 items[].correctAnswer + explanation）
- 此时才展示正确答案和解析

### 5.2 隐私边界（09-UI §11.1）

- 所有 UUID 显示走 `ShortId` 组件（只显示前 8 位 + "…"，如 `a1b2c3d4…`）
- 错误消息走 `ErrorState` 组件（只显示中文可操作消息，不含内部栈/SQL/路径/UUID）
- 测试断言：渲染输出 HTML 不含完整 UUID 正则匹配（36 字符格式）

### 5.3 规则优先（09-UI §4.3 + §7.4）

- HomeTab 的 `tasks.dailyBrief` 是规则聚合（非 AI），UI 不展示 AI 幻觉为事实
- 测试断言：HomeTab 渲染 dailyBrief 数据，不调用 AI 相关 RPC

### 5.4 知识模块回链（09-UI §4.5 + §7.3）

- NotesTab 知识模块列表展示 moduleName + learnStatus + sourceEvidenceJson（回链）
- 测试断言：知识模块卡片渲染 sourceEvidence 非空提示

### 5.5 错因六分类 + AI 不确定标记（09-UI §4.7 + §7.3）

- MistakesTab 错因确认展示六分类（concept_unclear/misread/formula_error/step_missing/time_pressure/other）
- AI 建议带"不确定"标记（suggestion + confidence），学生必须手动确认
- 测试断言：渲染六分类选项 + AI 建议含"仅供参考"字样
