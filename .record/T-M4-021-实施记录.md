## 4. 问题及根因

| # | 问题 | 根因 | 修复 |

| 1 | `pnpm package:win` 反复失败（Timeout awaiting request 600s / ETIMEDOUT / ECONNRESET） | electron-builder 需下载 winCodeSign（缓存缺失）+ electron zip（~116MB），GitHub CDN 本机不可达/极慢 | 手动缓存 winCodeSign（校验和 `cdaec715...` 匹配）+ 从 npmmirror 下载 electron zip（20MB/s）放入 builder 缓存 + ELECTRON_MIRROR 环境 |
