## 1. 任务裁决与范围

- **用户指令**：读取 `H:\pi-references` 中提供的 AI 原站、中转站与 API key，配置到 pi-studybuddy，并区分文本模型和支持多媒体的多模态模型。
- **范围**：登记可识别 provider 与非敏感模型 catalog；凭证仅通过 Electron 主进程 safeStorage/Windows DPAPI 写入本机 vault；默认模型切换先创建生产 pi session，成功后才持久化；对话选择器排除图像和视频生成模型。
- **非目标**：不联网探测未知中转站，不猜测未提供的模型 ID，不发送学生数据或真实对话请求，不实现图片附件消息 payload。

## 3. 偏差

- 初次完整回归发现旧 `models.list` 集成测试错误假设每个 provider 均有至少一个模型。根据用户提供资料，3 个中转站只提供线路和凭证，未提供模型 ID；测试改为断言它们可见且模型列表为空，避免伪造配置。
- 本机不变量脚本初次使用了不存在的 `defaultModel` 嵌套字段；实际 `models.json` 使用根级 `provider/model` 字段。脚本已按真实文件格式复验。

## 4. 问题及根因

| 问题 | 根因 | 处理 |
|---|---|---|
| 全量回归中 `models.list` 失败 | 历史测试将 provider 可用性等同于已知模型清单 | 明确区分已声明模型与待受控探测的 provider，新增正反断言。 |
| 旧默认 DeepSeek 与仅 Agnes runtime catalog 不一致 | 配置可见不等于生产 runtime 可创建 session | 补齐所有已识别 provider catalog，并将默认模型设为 Agnes。 |
| 模型切换可能先写配置后建 session | 失败会使持久化默认模型指向不可用配置 | 先创建新 session，成功后替换旧 session 并写 `models.json`。 |

## 5. 关键决定及依据

| 决策 | 依据 |
|---|---|
| 密钥仅存本机 DPAPI vault | AGENTS.md §9.2、§9.3、§8.5；仓库和日志不保存真实 key。 |
| 中转站不猜测模型 ID且不联网 probe | 用户只提供 key/线路；AGENTS.md §5.4 禁止不受控外部服务调用。 |
| 图像/视频生成模型不作为 ChatTab 选项 | 用户要求区分文本与多媒体模型；生成端点不能伪装为聊天模型。 |
| 现有 provider 配置按 ID 保留 | 防止升级默认 catalog 覆盖用户的 base URL、API 类型或模型定义。 |
| 切换 session 后才写默认值 | 防止 credential 缺失或 session 创建失败时破坏原可用配置。 |
