## 3. 偏差

- **无范围偏差**。两处实现细节修正（不改权威语义）：
  1. 无目标 Tab 白名单实现从"前缀匹配（studybuddy_tts_ / studybuddy_backup_）"改为**后缀白名单表**——因 backup 域 `restore_course / list_backups / configure_backup_schedule` 不以 `studybuddy_backup_` 开头，前缀匹配会漏判
  2. 测试自身一处断言修正：35 工具全覆盖测试的"无目标 Tab 白名单"校验从正则 `/^(studybuddy_tts_|studybuddy_backup_)/` 改为**备份域 5 工具显式清单**（同上原因）
- AppShell 接线从"直接引用 setActiveTabId"改为 **renderTab 参数传递**——renderTab 是模块级函数，无法访问组件内 state（TS2552），改为显式参数注入

## 4. 问题及根因

| 问题 | 根因 | 解决 |
|---|---|---|
| backup 域 3 工具漏判为"可跳转" | NO_JUMP_PREFIXES 前缀白名单 `studybuddy_backup_` 不匹配 restore_course/list_backups/configure_backup_schedule | 改为 NO_JUMP_TOOL_SUFFIXES 显式后缀表（tts 3 + backup 5） |
| ChatTab 注释 `<Tab名>` 触发 esbuild 解析错误 | JSX 注释中尖括号被解析为元素 | 注释改为"去目标 Tab 名" |
| `setActiveTabId` 在 renderTab 内不可见（TS2552） | renderTab 是模块级函数，AppShell 组件内 state 不在其作用域 | renderTab 增加 `onNavigateTab` 参数，调用处传 `setActiveTabId` |
| 三文件合并跑时 tool-tab-map 1 失败 | 测试自身正则断言与实现前缀白名单同源缺陷 | 测试改备份域显式清单 + 实现改后缀白名单（对应修复） |
