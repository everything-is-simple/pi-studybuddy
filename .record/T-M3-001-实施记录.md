## 3. 偏差

- 计划草案中"发送消息 → agent 流式响应的最小闭环（mock 或受控夹具）"落地为受控夹具事件序列（message_start→token×6→context_compressed），无真实 LLM——与 08-Test §5.4 一致，无偏差。
- ChatTab 会话列表加载：SSR 静态渲染测试中 useEffect 不执行，改为 initialSessions props 注入验证渲染——测试策略微调，实现不变。
- 06-API spec 同步在收尾阶段完成（计划§七原定步骤 13）——按计划执行。

## 4. 问题及根因

- **RED 阶段**：session-store 测试"无 fixture 时 list 为空"失败——实现默认注入 fixture 与测试意图冲突。根因：createSessionStore 缺省参数语义不明确。修复：缺省为空列表，默认 fixture 由 agent-host 装配时显式注入（defaultSessionFixture()）。
- **RED 阶段**：集成测试 agent-host 装配抛 `defaultSessionFixture is not defined`。根因：index.ts 新 import 遗漏。修复：补 import。
- **SSR 测试**：ChatTab 会话列表静态渲染断言失败。根因：renderToStaticMarkup 下 useEffect 不执行，异步 sessions.list 无法渲染。修复：测试改用 initialSessions 注入验证。
