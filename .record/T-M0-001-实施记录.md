## 3. 偏差

- **check-contract-coverage.mjs 期望路径修正**：原脚本写死 `src/agent-host/handlers.ts`（单一文件），与计划 §3 文件清单（`src/agent-host/handlers/ping.ts` 目录结构）不一致。收尾时修正为扫描整个 `src/agent-host/` 目录的 `server.handle({...})` 注册。
- **pnpm v11 `allowBuilds` 取代 `onlyBuiltDependencies`**（见 §4/§5）。

## 4. 问题及根因

- **pnpm install 报 `ERR_PNPM_IGNORED_BUILDS`**：pnpm v11 将 `onlyBuiltDependencies` 等旧配置移除，改为 `allowBuilds`（键值映射）。pnpm-workspace.yaml 中残留的非法 `allowBuilds: electron: set this to true or false` 占位块导致解析异常。根因：pnpm 11 配置 schema 变更 + 自动化占位写入。
- **verify 子步骤触发 pnpm deps-status-check**：install 未通过时，任何 pnpm 子命令都会先做依赖状态检查并失败。修复 allowBuilds 后解决。

## 5. 关键决定及依据

- **删除 electron-builder.yml**：01-TRD §7 决策 6（v0.1 源码形态不打包 .exe）+ AGENTS.md §6.4（禁止为将来提前设计 v0.2 产品化机制）。用户批准。
- **pnpm-workspace.yaml 采用 `allowBuilds: { electron: true, esbuild: true }`**：pnpm v11 官方 settings 文档（https://pnpm.io/settings/build#allowbuilds）指定的新格式。
- **check-contract-coverage 扫描 agent-host 目录而非单文件**：与计划 §3 文件清单（handlers/ping.ts 目录结构）对齐，避免校验脚本与实现结构脱节。
