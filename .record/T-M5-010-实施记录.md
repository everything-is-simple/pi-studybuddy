## 1. 任务裁决与范围

用户裁决新安装暴露的设置页缺口必须完整修复，不能由 T-M5-005 既定干净机 UAT 替代。T-M5-005 保持 blocked，仅等待其原定的 S6 报告投递重启回读、真实备份恢复后业务数据完整性/重启回读、TTS 原生已复习持久化/重启回读；T-M5-010 是唯一 in_progress 任务。

本任务范围：模型供应商目录与所选模型测试、SMTP/飞书报告目标与投递状态/重试、单一完整学期备份包及恢复、重启介导的数据根迁移、设置页原生目录选择和工具安装能力真实性。自动化不连接真实 SMTP、飞书或模型服务，不读取/暂存安装器，不写生产数据。

## 2. 实际交付

- 模型运行时配置以业务数据根 `config/pi-models.json` 为来源；旧目录合并默认模型，保留 DeepSeek Flash/Pro、Agnes 文本模型和用户 provider 定义；模型选择测试使用当前 `{ provider, model }`，错误可见且不回显密钥、base URL 或响应正文。
- 设置页按 provider 保存凭据状态，空目录 provider 支持受控目录探测；工具项仅呈现可验证的发现/状态能力，不再展示无受控下载源的无效安装动作。
- S6 新增并装配 `reportTargets.list/create/update/delete` 完整 CRUD；凭据只保存 credential-vault 键引用。生产 SMTP/Feishu adapter 返回实际配置/网络错误，`deliveries.deliver/retry/list` 保留状态、错误和重试边界；受控 mock 继续仅用于自动化。
- `backup.allCourses` 改为生成单一 `BackupRecord` 的 `backup_type=semester` 学期包；包包含学期数据库业务表、资料 storage、exports 和关联报告目标，并写入 manifest/schema/hash。恢复先 staging 校验，再按 overwrite 确认导入、恢复资料/exports/目标并执行 SQLite integrity check。
- 数据根迁移增加受控 registry：复制并校验全部受管资产后只写入下一次启动的 pending root；启动时优先环境覆盖，其次消费有效 pending root，目标失败回退 active/default；活动进程不切换 SQLite 连接。Electron 主进程通过原生目录 capability 调度迁移。
- BackupPanel/SettingsPage 使用原生目录/文件选择能力，renderer 不显示绝对路径、凭据、完整 UUID 或堆栈。

## 3. 偏差

- 本任务没有新增 RPC 方法；现有 typed API 为 128 handlers。`backup.allCourses` 的实现已与原契约表返回类型修正为单个 `BackupRecord`，属于既有方法语义收敛。
- 自动化验证使用受控 fake delivery 和隔离 SQLite；真实 SMTP/飞书投递未执行，符合任务外部服务边界。
- 原生 UAT 已覆盖隔离根中的学期备份、zip 选择、overwrite 恢复、重启回读和数据根切换；未将该证据扩大为 T-M5-005 三条既定干净 Windows UAT 或 T-M5-007 全功能 UAT。

## 4. 问题及根因

- DeepSeek/Agnes 目录缺失：旧安装可能保存空 `models` 数组，旧合并逻辑只合并 provider 元数据而不补模型目录。修复为按模型 ID 合并默认运行时目录，并保持用户连接定义。
- 报告渠道“已配置”不等于有投递目标：凭据配置与 `parent_report_targets` 生命周期此前断开。修复为目标 CRUD、vault 键引用和 delivery 状态/重试链路。
- `backup.allCourses` 原先按课程生成多个课程包，不能表达整学期资产闭环。修复为 semester manifest 和单一 archive，恢复同时处理 semester/global/storage/exports 范围。
- 数据根此前只在启动时解析环境变量/默认值，没有持久化下一次启动切换、目标校验和回退。修复为 registry + copy/integrity validation + restart-mediated resolution。
- 目录输入缺少完整 native chooser closure；修复复用 `PiBridge.selectDirectory()`，不把路径交给 renderer 展示。

## 5. 关键决定及依据

- 模型元数据落 `<dataRoot>/config/pi-models.json`，模型选择落 `<dataRoot>/config/models.json`，不读取或修改 `~/.pi`；依据 AGENTS.md §9.5、docs/03 §2.3、docs/06 §3.13。
- 凭据与报告目标分离：目标只保存非秘密路由配置和 vault key 名；依据 AGENTS.md §9.2-§9.3、05-ERD parent_report_targets 设计。
- 生产 delivery 与 mock delivery 分离；自动化不得用 mock-success 证明真实外部投递；依据任务计划 §2/§3、docs/13 测试真实性约束。
- `backup.allCourses` 返回一个 `BackupRecord`，学期包的 manifest、hash、schema 和恢复范围一一对应；依据任务计划 §2.3、05-ERD §8、现有实现 `packSemester/restoreSemester`。
- 数据根切换必须经下一次启动完成，不能在活动 SQLite 连接上切换；环境根优先级最高；依据任务计划 §2.4、AGENTS.md §9.5 和 `src/main/data-root-init.ts`。
- 原生 UAT 与自动化证据分开记录，不能互相替代；依据 AGENTS.md §7、docs/08 §6.6、docs/13。
