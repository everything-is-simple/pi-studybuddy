## 4. 问题及根因

| 问题 | 根因 | 修复 |
|---|---|---|
| 首次真实 runner：`No API key found for agnes` | loader 创建 AgentSession 时未把带 key 的 `modelRuntime` 传给 `createAgentSessionServices`，内部 runtime 无 key override | `createAgentSessionServices({ ..., modelRuntime })` |
| 全应用链路 `MODEL_NOT_CONFIGURED` | agent-host 在 utilityProcess 中，`require("electron").safeStorage` 为 undefined（实验确认 `{"electronSafeStorage":"undefined"}`）→ vault 抛错 → key 读取 null | 按 pi-desktop 范式：vault 只在 main 主进程持有，agent-host 经 parentPort 委托（新增 credential-client + main ipc.ts 响应） |
| verify-app 首次运行 tokenEvents=0 | agnes 首次请求较慢（elapsedMs 11.6s，thinking 模型），500ms 观察窗内未收到流式 token（agent.send 事件先回） | 非缺陷；重跑 3.9s 正常返回 17 事件/32 token；后续观察窗足够 |

## 5. 关键决定及依据

| 决定 | 依据 |
|---|---|
| 用 `pi-models.json`（ModelConfig 文件）注册自定义 provider，而非注入 `builtins` | pi `ModelRuntime.builtins`/`rebuildProviders` 均 private；文件方案与 `composeModelProvider` / `apiFrom("openai-completions")` 原生兼容；01-TRD §7 决策 1/2 |
| 保留 `allowModelNetwork: false` | 只影响启动时 refresh availability，不影响实际 stream/prompt（已确认 prepareRequest 无此检查） |
| model-config 与 pi-models.json 分离 | `models.json` 存业务别名（provider/model），`pi-models.json` 存 provider 定义，密钥存 DPAPI vault；职责隔离 |
| 凭证委托走 parentPort（不新增 RPC 方法） | utilityProcess 唯一 IPC 通道是 parentPort；复用既有 forkAgent message 处理；不扩 contract |
| credentials.* 改 async 但方法签名不变 | RPC server 支持 Promise；前端契约无需变更（contract 覆盖保持 127/127） |
| 错误不回传底层详情（固定"凭证库操作失败"） | AGENTS.md §9.3 日志脱敏 / §9.2 密钥边界 |
