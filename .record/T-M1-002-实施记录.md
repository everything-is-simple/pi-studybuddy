## 3. 偏差

1. **check-docs-governance.mjs regex 不兼容 CRLF**：04-Todo 文件因 Windows 编辑产生 CRLF 行尾，治理脚本 regex `\n` 无法匹配 `\r\n`，导致头部三字段检查误报。修复：regex 改 `\r?\n` 兼容两种行尾。影响：治理脚本健壮性提升，非业务偏差。
2. **AGENTS.md 头部版本号滞后**：v0.1.7-9 仅同步 §3.1 表格版本号但未更新头部 `**版本**` 字段（滞留在 v0.1.6）。本次 v0.1.10 修正头部版本号滞后（v0.1.6→v0.1.10）。影响：版本号一致性，无权威条款变更。

## 5. 关键决定及依据

1. **S2 Job 仅登记 pending 不进入 running**：依据 07-WF §8.4 状态机 + 任务计划"不做"清单（转换器/AI 未实现）。Job 登记为 pending 状态，状态机校验仍实现（为后续任务预留），但本任务不执行转换/AI。
2. **DTO 对齐 ERD 而非保留 types.ts 原值域**：依据权威链 05-ERD（优先级4）> types.ts（优先级7）。types.ts S2 五 DTO + JobStatus/JobType 共 8 处偏离 ERD，全部按 ERD 修正。
3. **MindMap 从树形对象改为字符串**：依据 05-ERD §3.2.4 `markmap_json` 字段为字符串权威。DTO 暴露 `markmapJson: string`，移除 `MindMapNode` 类型。
4. **storage_key 路径安全检查**：依据 05-ERD §3.2.1 触发器约束（拒绝 `..` / `:\` / `:/`）+ AGENTS.md §9.4 组件安全（符号链接逃逸防护）。
5. **findSemesterByMaterialId 不过滤 deleted_at**：软删除资料仍需可查（如 delete handler 需先找到再标记删除）。与 S1 findSemesterByEntityId 模式一致。
