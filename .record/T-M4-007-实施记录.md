## 1. 任务裁决与范围

用户明确批准 T-M4-007 的唯一计划并授权实施。本任务只实现左侧学期/课程树、壳层唯一学期/课程上下文、标题栏动态绑定、归档只读浏览提示、异步竞态/卸载保护及安全化展示；只使用现有 `semesters.list({})`、`courses.list({ semesterId })`。不修改 RPC 契约、handler 或 schema，不写真实 `%LOCALAPPDATA%\PiStudyBuddy`，不连接真实外部服务，不启动 T-M4-008。

## 2. 实际交付

- 新增 `src/renderer/semester-course-state.ts`：受控状态、按 `semesterId` 隔离的请求 gate、过期结果处理、当前上下文派生和 UUID/路径/Bearer/stack 安全显示。
- 新增 `src/renderer/components/SemesterCourseTree.tsx`：学期树、展开/收起、课程 loading/empty/error、状态点、archived 的“已归档（只读）”和可访问课程组名称。
- 修改 `src/renderer/components/AppShell.tsx`：以单一状态源加载学期/课程、传递既有 Tab 的 `semesterId/courseId`、绑定标题栏、保留 Tab 与设置页往返状态，并在 archived 上下文显示工作台只读浏览提示。
- 新增 unit / RPC integration / happy-dom AppShell 实挂载测试；`happy-dom@20.11.2` 仅作为开发期 Vitest DOM 环境，不进入 Electron 生产包。

## 3. 偏差

已有真实 Electron + `127.0.0.1` TCP E2E harness 验证生产 Electron 主进程/RPC 路径，但不观察 renderer DOM。因此，课程 deferred-RPC 乱序、标题更新、Tab 切换与设置页往返由 happy-dom 实际挂载 AppShell 的集成测试覆盖；不将 TCP harness 记为 renderer DOM 验收。

“archived 禁止非法写操作”的落点限定为本任务不提供学期/课程创建、更新、归档、导入或 S1-S7 业务写 RPC。现有业务 Tab 的相关写入口尚未在本任务范围内接线；逐控件的 disabled/aria-disabled/写 RPC 阻断留给后续业务接线任务，避免误拦截会话、设置或占位控件。

## 4. 问题及根因

- 初版课程请求 gate 以全局序号判断新旧，跨学期并发时会把另一个学期的合法请求误判为过期；改为以 `semesterId` 分区的 `Map` 令牌。
- 初版安全展示未覆盖 UUID v7；补充 canonical UUID、Bearer、Windows/UNC/file URI/POSIX 路径、异常/多行 stack 的统一中文回退。
- 初版 archived 只在树上显示，未把只读属性派生进 AppShell 当前上下文；改为 `deriveAcademicContext()` 随当前学期列表实时计算 `isReadOnly`，并补充归档课程组可访问名称。
- Erdos 审查指出纯 reducer 不能代替 AppShell 实际异步路径；新增 happy-dom + deferred RPC 实挂载测试。
- 治理基线曾滞后于当前索引、Todo、计划和记录状态；本记录与治理文档在收尾阶段同步修正。

## 5. 关键决定及依据

- 单一上下文放在 `AppShell`：依据 09-UI §3、03-Architecture §6.7 和用户附件“当前学期/课程在壳层有单一来源”。
- 仅读取既有两项 RPC：依据 06-API 与用户附件第 290-297 行；不新增 API。
- 请求令牌按学期隔离并在卸载时失效：依据用户附件第 335-339 行的竞态/卸载要求。
- 采用 `happy-dom` 进行 renderer 实挂载：真实 Electron TCP harness 不可观察 DOM，且依赖只用于测试。
- archived 仅表达当前任务可验证的只读浏览语义：依据用户附件第 349-359 行“不接线 S1-S7 业务 Tab 的具体 RPC”，避免跨越 T-M4-008 及后续业务接线范围。
