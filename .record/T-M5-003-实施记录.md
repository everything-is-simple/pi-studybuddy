## 5. 关键决定及依据

1. **会话持久化 = `<dataRoot>/sessions.json`**（业务数据根状态文件，与 models.json 同级，非 DB schema）——满足「重启可见」且不破坏「不新增 API/schema」（AGENTS.md §4.4 约束；06-API §3.1 无 create 契约）。
2. **新建会话 = renderer 真实 ID + agent.send 首条消息 host 侧物化（touch）**——contract 保持 127/127；touch 先于模型检查，失败路径不丢会话。
3. **turn_end L3 索引归属真实会话（用户裁决）**——`agent.send` 写 `sessionIdRef` → 扩展 `getSessionId` 读取 → 删除 sess-001 回退。
4. **失败可见（固定中文文案）**——错误文案收敛 `chat-errors.ts`，只按错误码映射，不泄漏原始 message/路径/栈（AGENTS.md §9.3）。
5. **重命名改内联编辑**——Electron 不支持 window.prompt（P1），真实会话管理闭环必须可用。
