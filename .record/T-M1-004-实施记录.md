## 3. 偏差

1. **ErrorCauseAdvisor 默认 mock 不接真实 LLM**：依据计划"不做"清单 + 08-Test §5.4 不连真实外部服务。suggestErrorCause 调用可注入的 ErrorCauseAdvisor 接口（默认 `createMockErrorCauseAdvisor()`），返回带"不确定"标记的建议 + confidence='low'。AI 失败时 throw INTERNAL_ERROR + "AI 建议暂时不可用，请手动选择错因"。真实 LLM 接入待后续任务。影响：测试可重复性 + 不依赖外部服务，符合 TDD 纪律。
2. **mistake_evidence.source_practice_answer_id 改为可空**：依据 05-ERD §3.4.2 原 NOT NULL 约束。redo 证据（redo_wrong 类型）不依赖新 practice_answer（重做不在 practice_answers 表写记录，仅写 mistake_evidence），但原 NOT NULL 约束导致 redo 时 INSERT 失败。修改为可空（redo 证据 source_practice_answer_id=NULL；initial_wrong 证据仍有值）。影响：schema 一致性保持，UNIQUE(source_practice_answer_id) 仍防重复归档（NULL 不参与 UNIQUE 比较）。
3. **redo 不写 practice_answers 记录**：依据 07-WF §2.5（redo 是错题本内重做，不是新练习 session）。redo 证据仅写 mistake_evidence（evidence_type='redo_wrong'），不在 practice_answers 表新增记录。原因：规避 UNIQUE(practice_session_id, question_id) 约束（同一 session 同一 question 只能一条答题）+ T5 触发器校验。影响：redo 证据与 initial_wrong 证据在 mistake_evidence 表区分（evidence_type 字段）。

## 5. 关键决定及依据

1. **幂等归档先查后插**：依据 07-WF §2.5 + 05-ERD §6.4 trg_mistake_idempotent_archive。archive 先查 question_id 是否已有 mistake；有则追加 mistake_evidence（UNIQUE(source_practice_answer_id) 防重复归档同一答题，冲突时幂等返回已有 mistake）；无则新建 mistake(status=needs_review)。约束：幂等归档保证同一答题不产生重复错题，同一 question 不产生多个 mistake。
2. **S4 只读 S3 事实**：依据 07-WF §2.5（S4 不反写 S3）。archive 通过 practiceAnswerId 查 practice_answers（必须 is_correct=0），不修改 practice_answers。约束：S3 批改结果作为 S4 归档事实来源，S4 不影响 S3 数据。
3. **错因学生确认制**：依据 02-PRD §3.4 + 07-WF §2.5。AI 只提建议（带"不确定"标记 + confidence），学生必须确认；error_cause_confirmed_by='student'。AI 失败→INTERNAL_ERROR 降级，不阻塞学生手动确认。约束：AI 不凌驾学生决策。
4. **evidence_count≥2 才形成薄弱点**：依据 07-WF §2.5 + 05-ERD §3.4.3。单次错误不形成永久薄弱点。redo 正确后若 evidence_count≥2 且 mistake 有 knowledge_module_id 则归纳 weak_point（UNIQUE(course_instance_id, knowledge_module_id) 防重复）。约束：避免单次错误噪声形成薄弱点。
5. **redo 不写 practice_answers**：依据 07-WF §2.5（redo 是错题本内重做）。redo 证据仅写 mistake_evidence（evidence_type='redo_wrong', source_practice_answer_id=NULL）。约束：规避 UNIQUE(practice_session_id, question_id) + T5 触发器冲突。
6. **mistake_evidence.source_practice_answer_id 可空**：依据 05-ERD §3.4.2。redo 证据天然无 source_practice_answer_id。修改 NOT NULL → 可空。约束：UNIQUE(source_practice_answer_id) 仍防重复归档（SQLite UNIQUE 允许多个 NULL）。
7. **错题状态机 needs_review↔mastered**：依据 07-WF §8.6。redo 正确→mastered；mastered 后 redo 错误→回退 needs_review（mastered_at 清空）。约束："已掌握"非终态，可回退。
8. **薄弱点状态机 active→resolved→regressed**：依据 07-WF §8.7。resolve：active→resolved；regress：resolved→regressed。resolved 可被 regress 回退（新错误触发）。约束："已解决"非终态。
