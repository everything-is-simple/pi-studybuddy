## 3. 偏差

- **无范围偏差**。唯一实现细节调整：agent.send 的 [学习上下文] token 注入从"异步 buildStudyContextSections"改为**同步注入**（subject/goal/mistakeIds 直接拼段）——因为异步注入会破坏受控序列的确定性（token 顺序不可测），错题详情读取归 before_agent_start 钩子（context-pack mistakeLookup）而非受控发射路径。此调整不改变权威语义（09-UI §4.2 上下文注入），仅在承载层实现层面修正。
- L1 写回模块初稿放 `src/data/l3/l1-profile.ts` 后移动到 `src/data/l1-profile.ts`（L1 ≠ L3，目录职责隔离 docs/12）。

## 4. 问题及根因

| 问题 | 根因 | 解决 |
|---|---|---|
| 完整 UUID 仍可被检索 | UUID 被 `-` 拆成 5 段 ASCII 词，逐段索引后 OR MATCH 可命中 | 分词前 UUID_IN_TEXT_RE 整体剥离子串（正则 + `\b` 边界） |
| chunks DDL 重复执行抛 "table already exists" | CREATE TABLE / CREATE VIRTUAL TABLE 非幂等 | openConversationDb 增加 sqlite_master 存在性检查（不修改治理 DDL 文件 conversation.sql.ts） |
| "await can only be used inside async function" | buildStudyContextSections 原为返回 Promise.resolve 的非 async 函数，新增错题查找后需要 await | 改为 async 函数（签名不变） |
| 测试误调 `again.close()` | DataDb 是 { path, db } 结构 | 测试改 `again.db.close()` |
| 06-API/04-Todo 头部版本号滞后 | 前序任务收尾未同步头部字段 | 本次登记一并修正（04-Todo v0.1.52→v0.1.54、06-API v0.1.2→v0.1.4，AGENTS.md v0.1.10 同型先例） |
