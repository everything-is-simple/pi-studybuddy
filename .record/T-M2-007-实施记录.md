## 4. 问题及根因

- **whisper-cli 参数识别失败**：初始 `whisper-cli.exe -m model -f file -nt` 命令退出码 2 显示帮助。**根因**：参数顺序/`-nt` 有效性需验证。**修复**：经 `whisper-cli --help` 确认 `-nt`（no-timestamps）为合法参数，确认参数顺序后对合成 WAV 成功转录。
- **合成 WAV 生成**：需含真实音频数据（纯 44 字节空头会被识别为空白音频）。**修复**：测试内 `buildSineWavBuffer` 生成 16kHz/mono/16-bit PCM WAV 含 3s 正弦波 data chunk。
- **临时文件清理**：测试 WAV 文件残留导致隔离目录不干净。**修复**：`afterAll` 加重试强制删除隔离目录（忽略 EBUSY）。

## 5. 关键决定及依据

- **配置来源双通道（调用参数 + 环境变量）**：settings RPC handler 未实现（仅契约），为避免过度工程（AGENTS.md §6.4），采用环境变量 + 调用参数双通道，对齐现有 `resolveDataRoot` 的 `PI_STUDYBUDDY_DATA_ROOT` 环境变量范式。优先级：调用参数 > 环境变量 > 空（默认 mock）。
- **无配置默认 mock**：测试环境不配置 → 默认 mock，不连真实 whisper.cpp（08-Test §5.4）；集成/E2E 保持 mock（08-Test §9.3）。
- **真实转写测试只断言 text 非空 + 无泄漏字段**：合成正弦波转录文本不确定（可能为环境音描述），不断言具体文本内容（计划 §10 风险与缓解）。
