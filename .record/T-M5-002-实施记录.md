## 4. 问题及根因

- **管理面板遮挡 TabBar**：planningView 最初整体替换 `<main>`，用户进入管理面板后无法切 Tab。根因：渲染优先级设计错误。修复：TabBar/TTS 常驻，仅内容区被规划视图替换；切 Tab 自动退出规划视图。真机 UAT 抓到后修复并复验。
- **UAT 驱动两次超时**：executeJavaScript 长脚本返回含不可克隆对象 → 主进程拿不到结果 → 90s 超时；以及重启阶段运行器误删第一阶段数据根。根因：脚本返回值可克隆性与运行器数据根生命周期。修复：改主进程逐步 executeJavaScript（每步纯 JSON），第二阶段不重置数据根。

## 5. 关键决定及依据

- 归档防线放 host 层（`assertSemesterWritable`），而非仅前端禁用——依据 AGENTS.md §9.4/§8 与 S3/S5/S6 既有先例；直接 RPC 也无法绕过只读。
- 归档前备份以"勾选已在备份中心完成备份 + 跳转备份 Tab"实现，不假装自动备份——避免未经证实的自动归档备份承诺（T-M4-007 TODO 未实现）。
- 创建成功后即时写入 AppShell 唯一上下文并进入首页，不要求重启——符合"用户创建后下一步可见可操作"。
