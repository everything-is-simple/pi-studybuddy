## 5. 关键决定及依据

| 决定 | 依据 |
|---|---|
| S5 属 M2 而非 M1 | 04-Todo §6.4（M2 范围含 S5）权威链优先级5 > .plan（优先级6）；S5 是 M2 首任务故序号 001 |

| MockExamGenerator 可注入接口 | 08-Test §5.5 AI 降级 + 参考 S3 QuestionGenerator 模式；默认 createMockMockExamGenerator + createFailingMockExamGenerator 测试失败降级 |
| cramCards/cramPlan 确定性只读 DTO | 任务铁律：不建表、不持久化、不依赖 AI、不替学生改写事实；同输入同输出 |
| 复用 S3 grader 三策略批改 | 06-API §3.7 + DRY；单选精确/多选 deepEquals/填空 normalize+多等价 |
| AI 失败不创建空卷→INTERNAL_ERROR | 08-Test §5.5 AI 降级；与 S3 createSession 一致 |
| getPaper 未提交不含 correct_answer | 06-API §471 防泄露 + 与 S3 getQuestions 一致 |
| 模块分析 weakness_level 阈值 0.8/0.5 | strong(≥0.8) / medium(≥0.5) / weak(<0.5)，按 accuracy_rate 分级 |
