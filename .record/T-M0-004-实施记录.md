## 3. 偏差

### 3.1 MINIMUM_NODE_VERSION 调整

**计划**：MINIMUM_NODE_VERSION = "22.19.0"
**实际**：MINIMUM_NODE_VERSION = "22.0.0"

**原因**：实际环境 Node v22.16.0 低于计划阈值 22.19.0，导致 NODE-PROBE-01 返回 "unsupported"。

**影响**：无。v22.16.0 仍在 Node 22 大版本内，且高于架构最低要求。

### 3.2 discovery-registry readDirectoryNames 过滤修正

**计划**：readDirectoryNames 返回目录条目
**实际**：readDirectoryNames 返回可执行文件条目（`entry.isFile()`）

**原因**：PATH 扫描需要枚举可执行文件而非子目录。原实现 `entry.isDirectory()` 过滤导致 PATH 扫描找不到任何可执行文件。

### 3.3 capability ID 到可执行文件名的映射

**问题**：`discoverCandidates("js.node")` 搜索 `js.node.exe` 而非 `node.exe`

**修复**：在 manager.ts 新增 `executableNameForCapability()` 映射函数，将 "js.node" → "node"、"vcs.git" → "git" 等。

### 3.4 agent-host handler 参数类型

**问题**：`toolchains.install` handler 参数类型 `{ capabilityId: string }` 与 `RpcHandler` 签名 `(...args: unknown[])` 不兼容。

**修复**：将参数类型改为 `unknown`，内部 cast。
