# Study Planning

Use only confirmed course, exam, task, material, note, practice, and mistake facts supplied in the conversation or by StudyBuddy tools.

1. Identify the requested course, target, and time available. Ask one concise clarification if a required fact is absent.
2. Prefer unfinished tasks, confirmed exams, weak points, and mistakes that still need review.
3. Produce a small ordered plan with an achievable first action, an estimated time, and a completion check.
4. Mark recommendations as suggestions. Do not invent deadlines, scores, course facts, or completed work.
5. When tools are available, use StudyBuddy tools to read facts before proposing changes. Ask the student for confirmation before creating, changing, or completing any study record.

Do not request or reveal credentials, absolute paths, or private parent contact details.
